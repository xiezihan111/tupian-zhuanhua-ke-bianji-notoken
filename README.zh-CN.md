# 图片转可编辑 PowerPoint

**下载：[本地代码包 ZIP](https://github.com/xiezihan111/editable-ppt-from-images/raw/refs/heads/main/image-to-editable-ppt-local.zip)**

此代码包可将图片信息图重建为可编辑 PPT：文字框、框架、箭头、数据流和连接线为 PowerPoint 原生对象，设备按原图坐标裁成可单独移动的图件。配有 Jupyter Notebook、Python 导出器和本地标注工具。

无需 API Key，不调用大模型；图片在本机处理。设备内部纹理仍是位图。新图片需人工校对 OCR 文字和裁图范围，不能保证一键无损矢量化。ZIP 仅含通用代码和原创示例，不含教材图片。

快速开始请解压 ZIP，查看 `README.md`，然后在 Jupyter 中运行 `start.ipynb`。
