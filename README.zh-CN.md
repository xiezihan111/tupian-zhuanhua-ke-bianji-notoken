# 图片转化可编辑文件（notoken）

**下载：[本地代码包 ZIP](https://github.com/xiezihan111/tupian-zhuanhua-ke-bianji-notoken/raw/refs/heads/main/image-to-editable-ppt-local.zip)**

这是一个本地运行的图片转可编辑 PowerPoint 工具包，包含 Jupyter Notebook、Python 导出器和本地标注工具。文字、框架、箭头、数据流和连接线会生成可编辑的 PowerPoint 对象；裁出的设备图件可以单独移动和替换。

无需 API Key，不调用大模型，处理过程不消耗模型 Token。设备纹理仍为图片；新图需人工校对文字识别和裁图范围，不能保证一键无损矢量化。代码包仅含通用代码和原创示例，不含教材图片。

**快速开始：**解压 ZIP，查看 `README.md`，然后在 Jupyter 中运行 `start.ipynb`。
